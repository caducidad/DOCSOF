## Descripción de la tarea (memoria, pág. 60–62)
Integración del algoritmo de IA en una aplicación web que permita a los usuarios cargar su código de interfaz de usuario, analizarlo con el algoritmo y recibir sugerencias para mejorar la accesibilidad.

## Línea L3.6 (contexto)
- **Meses:** M1–M36 · **Líder:** PROXYA · **Colaboradores:** UMA, Grupo AZVI · **Subcontratista:** FIDETIA
- **Estado del arte en la memoria:** sección 2.2.13.
- **Descripción:** sistema accesible vía aplicación web que adapte o corrija automáticamente el código de interfaces de usuario para cumplir buenas prácticas y reglas de accesibilidad (W3C, ADA, EN 301 549…), para cualquier tipo de código (HTML, React, Angular…). Caso específico adicional: cuadros de mando adaptativos para inteligencia de negocio (T3.6.4).

**Objetivos:**
- O3.6.1: algoritmo de IA que adapte o corrija el código de interfaces para cumplir los estándares de accesibilidad.
- **O3.6.2: aplicación web para cargar código, analizarlo y recibir sugerencias.** ← objetivo directo de este entregable
- O3.6.3: mejorar un **60 %** el cumplimiento de estándares de accesibilidad de las interfaces tratadas.
- O3.6.4: funcionar con cualquier tipo de código de interfaz (HTML, React, Angular…).
- O3.6.5: interfaces de sistemas de monitorización adaptables dinámicamente al usuario.

**Retos tecnológicos:** algoritmo que analice y adapte/corrija distintos tipos de código de interfaz; integración efectiva del algoritmo en la aplicación web; funcionamiento en distintos contextos tecnológicos.

**Indicadores:**
- **I3.6.1:** reducción del tiempo de adaptación y aseguramiento de cumplimiento = [(T. inicial − T. final) / T. inicial] × 100. Objetivo **≥ 60 %**.
- **I3.6.2:** % de proyectos de la empresa compatibles según su tipo de código de interfaz = (compatibles / total) × 100. Objetivo **≥ 60 %**.
